01 — Overview

What is Neuro-Net?

Neuro-Net is a deep learning sandbox that implements a neural network entirely from scratch in Python using Object-Oriented Programming principles. Unlike frameworks like TensorFlow or PyTorch, every mathematical operation — forward propagation, loss calculation, backpropagation, and weight updates — is coded explicitly.

The project classifies Iris flower species (Setosa, Versicolor, Virginica) from four petal and sepal measurements, achieving over 85% prediction accuracy on previously unseen data.

04 — Module Documentation

Key Components

🧠

NeuralNetwork Class

Core OOP class managing the network topology. Initialises synaptic weights randomly (range –1 to 1, mean 0), exposes train() and think() (predict) methods.

📈

Sigmoid Activation

Normalises weighted sums to the [0, 1] range. The derivative σ(x)·(1–σ(x)) is used during backpropagation to scale weight adjustments by confidence.

⚡

Stochastic Gradient Descent

Weight update rule applied at every iteration. Adjusts weights proportionally to the error multiplied by the sigmoid gradient, ensuring uncertain weights change more.

🌸

Iris Entry Point

Iris.py loads the dataset, splits into training/test sets, initialises the network, runs 10,000 training iterations, and reports final accuracy.

📦

Data Pipeline

Reads the Iris CSV (150 samples, 4 numeric features), applies normalisation, and encodes the 3 species labels before feeding into the network.

🎯

Output Layer

Three output neurons (one per class: Setosa, Versicolor, Virginica). The neuron with the highest activation value determines the predicted class.

06 — Mathematics

Key Formulae

Sigmoid Activation
σ(x) = 1 / (1 + e⁻ˣ)
Maps any real number to (0,1). Acts as the neuron's "firing" decision.
Sigmoid Derivative
σ'(x) = σ(x) · (1 − σ(x))
Used in backpropagation to scale weight updates by confidence.
Weight Update (SGD)
W ← W + Xᵀ · (e · σ'(ŷ))
Adjusts each weight based on the error scaled by the gradient.
Forward Pass
ŷ = σ(X · W + b)
Matrix multiplication of inputs × weights, passed through sigmoid.

07 — Training Pipeline

Step-by-Step Training Flow

01

Load & Preprocess Iris Data

Read 150 samples with 4 features (sepal/petal dimensions). Normalise to [0,1]. Encode 3 class labels. Split into training and test sets.

02

Initialise NeuralNetwork

Random synaptic weights drawn from a uniform distribution in [–1, 1] with mean 0. Network topology: 4 inputs → hidden layer → 3 outputs.

03

Forward Pass

Each training sample is passed through the network. The dot product of inputs and weights is squashed through the sigmoid function to produce a prediction ŷ.

04

Compute Error

Error = true label − prediction. Larger errors indicate the network is less confident and requires bigger weight corrections.

05

Backpropagate & Update Weights

The adjustment = Xᵀ · (error × σ'(ŷ)) is computed and added to the weights. This runs 10,000 times, making increasingly small corrections.

06

Evaluate on Test Set

The trained model predicts species on held-out data. Performance consistently exceeds 85% accuracy on unseen samples.
